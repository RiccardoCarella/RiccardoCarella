### Featured project

#### [WoW Market Flip](https://github.com/RiccardoCarella/wow-market-flip)

A market-analytics web app for the World of Warcraft auction house. It ingests data from the Blizzard API and TradeSkillMaster and turns it into trading tools: Flip Finder, Shortage, Market Share, Snipe alerts and historical charts.

**Live:** [wow.riccardocarella.it](https://wow.riccardocarella.it)

- **Next.js (App Router) + TypeScript** monorepo with Turborepo and pnpm, UI in English and Italian (next-intl)
- **PostgreSQL + TimescaleDB** for time-series prices, Redis caching, background ingestion workers
- Sign-in with Discord or email and password, CSP with per-request nonces
- Accessible UI: ARIA patterns, full keyboard navigation, contrast-checked themes
- Dockerised and self-hosted on a VPS behind Cloudflare Tunnel, CI on GitHub Actions
- Built with an AI-assisted workflow (Claude Code) and documented architecture decisions
